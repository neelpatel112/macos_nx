# 🍏 macOS NX - Web-based macOS Desktop Clone

![macOS NX Desktop](wallpaper.jpg)

A fully functional macOS desktop environment built with vanilla HTML, CSS, and JavaScript. Experience the look and feel of macOS right in your browser!

## ✨ Features

### 🖥️ Desktop Environment
- Authentic macOS-inspired desktop interface
- Draggable, resizable windows with smooth animations
- Functional dock with app icons and hover effects
- Dynamic wallpaper support
- Window management (open, close, minimize, maximize)

### 📁 Built-in Applications

| App | Description |
|-----|-------------|
| **Finder** | File manager with folder browsing |
| **Music** | Music player with album art display |
| **Photos** | Image gallery viewer |
| **System Preferences** | Settings panel for customization |

### 🎨 Visual Polish
- macOS Big Sur/Sonoma inspired design language
- Smooth transitions and animations
- Blur effects and transparency
- Custom app icons
- Responsive dock with magnification effect

## 🚀 Live Demo

Experience it yourself: **[macosnx.vercel.app](https://macosnx.vercel.app)**

## 💻 Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Icons & Assets**: Custom SVG and PNG assets
- **Deployment**: Vercel
- **No frameworks or libraries** - built from scratch!
